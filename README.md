# Sistema de Gerenciamento de Biblioteca

Atividade Prática da disciplina **Fundamentos e Paradigmas de Programação**.
Este projeto implementa um sistema simples de gestão de biblioteca com suporte a cadastro, listagem, empréstimo, devolução e persistência em arquivo JSON, desenvolvido em 3 diferentes paradigmas de programação.

---

## 🚀 Como Executar

Certifique-se de ter o **Python 3.x** instalado no seu ambiente.

1. Baixe ou clone os ficheiros para a mesma pasta.
2. Abra o terminal na pasta do projeto.
3. Executar a versão **Procedural/Imperativa**:
   ```bash
python biblioteca.py
